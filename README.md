# arunponraj.github.io
Business Website
This is a simple business website created using HTML, CSS, and JavaScript, hosted on GitHub Pages. It showcases the basic structure of a business website with sections such as About Us, Services, and Contact.
Purpose
The purpose of this website is to provide a basic template for a business website, showcasing information about the company, its services, and how to contact them. 
Technologies Used
HTML: For structuring the content of the webpage.
CSS: For styling and layout of the webpage.
JavaScript: For adding interactivity to the website (such as form handling).
GitHub Pages: For hosting the website for free.
